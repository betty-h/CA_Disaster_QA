# Q&A Dataset Generation Pipeline for CA Disaster Recovery

A pipeline for building and evaluating a benchmark dataset of question-answer pairs for a California disaster recovery chatbot. Questions are ecologically valid — reflecting how real people type under stress — and cover 34 topics across the full query distribution from high-volume (FEMA registration, housing) to long-tail (livestock, undocumented families, mold remediation). See `pipeline_overview.md` within the reports folder for details. Below are descriptions of the files in this repo.

---

## Scripts

| File | Purpose |
|---|---|
| `scrape_disaster_info.py` | Fetches and extracts clean text from ~33 authoritative public sources (FEMA, CalOES, SBA, EDD, CA DOI, etc.). Outputs `scraped_content.json`. |
| `generate_qa_pairs.py` | Uses the Claude API to generate ecologically valid Q&A pairs grounded in the scraped content. Outputs `qa_pairs.json` and `qa_pairs.jsonl`. |
| `evaluate_qa.py` | LLM-as-judge rubric evaluator. Scores model predictions against gold answers on six dimensions. Outputs `eval_results.json` and `eval_report.md`. |

### How to run

```bash
# 1. Install dependencies
pip install requests beautifulsoup4 trafilatura anthropic lxml

# 2. Set API key
export ANTHROPIC_API_KEY=sk-ant-...

# 3. Scrape sources (~2 min)
python3 scrape_disaster_info.py

# 4. Generate Q&A pairs (~5–10 min)
python3 generate_qa_pairs.py

# 5. Evaluate predictions
python3 evaluate_qa.py --predictions predictions.jsonl
```

## Data

| File | Size | Description |
|---|---|---|
| `scraped_content.json` | ~116 KB | Clean text extracted from 28 successfully scraped sources, plus the topic taxonomy used during generation. |
| `qa_pairs.json` | ~193 KB | 306 gold Q&A pairs across 34 topics and 6 writing styles. Array format. |
| `qa_pairs.jsonl` | ~185 KB | Same 306 pairs, one JSON object per line. Convenient for fine-tuning pipelines. |

> **Note:** `eval_results.json` and `eval_report.md` are generated by `evaluate_qa.py` at evaluation time and are not included until the script is run.
